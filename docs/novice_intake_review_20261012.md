# 新手收件／待辦表單修復

基底 `bf1872b48f4403d0bbaea9576c9b476a4c4ca15a`；合成資料，Linux 真 Qt offscreen，不代表 Windows EXE/DPI 人工验收。

## 可再現問題與最小修復

- 520×420 開新待辦、批量待辦、長檔名/50行備註附件資訊，原對話高度分別升到492、603、1025。加入可捲動內容，保存／取消／關閉維持底部；索件品項模板同樣可捲動。1366×768、1093×614、520×420各測五種對話，全部內容可以捲到末端，不壓縮字體。
- 新待辦客戶／案件讀取失敗原只記log並當「不指定」繼續儲存。現在顯示失敗、停用儲存、提供讀取重試並保留已輸入文字；真空仍可建立無關聯待辦。
- 新待辦原僅取500客戶／全域案件及選定客戶200案件。改分頁取得並驗證重複頁；201/501項可選。每種選單最多10,000筆，同步載入超限明確阻止不完整選取，提示從指定案件建立；不是無界迴圈。大量同步載入仍有速度限制，未宣稱虛擬化。
- 標題、承辦、下一步、備註補範例及選填提示；日期保留自由輸入及日曆。補標籤關聯、可辨識名稱及日期/備註Tab順序。未預填業務值、未改服務語意。
- 新待辦與兩種批量待辦僅有未儲存改動時，在取消／Esc／關閉提示放棄確認；預設繼續編輯，空表與成功提交不提示。
- 附件資訊保留PlainText與可選文字，長中文及路徑換行。品項新增限制說明可換行。

## 驗證與限制

`tests/test_novice_intake_forms.py`：38個真Qt案例，含三種視窗大小、長中文、空資料、故障與重試、重複分頁、限額、取消、真SQLite新增。既有plain-text安全測試改為尋找捲動內form，安全斷言完整保留。

既有索件模板、品項、批次真實路徑、待辦、附件、提醒、日期與dialog回歸另行逐檔執行，結果見本輪review交接。測試關閉dialog，fixture關閉合成SQLite；無網路、無server、无子process或背景worker新增。

未改message模板、客戶頁、年度頁、案件頁、共享widgets/tokens/style。收件頁640×480壓力窗仍被既有filter最小寬撐至813；900/1093/1366主要範圍由獨立QA另驗。未push/merge/release；獨立審查結果由審查者提供。

獨立QA指出備註編輯器預設吃Tab，補 `setTabChangesFocus(True)`；三個待辦對話的真鍵盤Tab確認抵達footer，未插入製表字元。

獨立QA再指出重試可能遺失已選客戶／案件ID，補失敗前ID保存與精確還原；失效ID及失效preset明確禁存，不默認無關聯。
