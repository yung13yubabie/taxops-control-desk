# TaxOps 0.33.0rc1 試用說明

這是候選版，先不要取代工作用版本，也不要匯入真實客戶或會計資料。

開始前
1. 請用空白測試電腦，或從未使用過 TaxOps 的新 Windows 帳號。先關閉這部電腦上所有 TaxOps 視窗。
2. 請勿在平常工作的 Windows 帳號直接試開。程式會讀取該帳號原有的 TaxOps 資料；把 EXE 複製到另一個資料夾，不會隔離資料。
3. 將整個 ZIP 解壓縮，再開啟 TaxOpsControlDesk.exe。請保留旁邊的所有檔案，不需另裝 Python。
4. 若 Windows 阻擋、缺檔或畫面空白，先停止，回報提示內容。不要關閉防護或自行替換套件內檔案。

建議先試這幾件事
- 新增「試用客戶」與案件，建立索件和待辦。
- 放入一份自己製作、沒有個資的小檔案，試收件、預覽及核對。
- 開啟年度工作，試設定、修改日期與記錄金額；確認改錯後能取消。
- 把視窗縮小、展開說明，檢查欄位、儲存與取消按鈕是否仍看得到。
- 到「資料與工具 → 設定 → 備份與還原」建立完整備份，再以剛才的假資料試還原。舊 .sqlite 只有資料庫，不包含附件。
- 關閉網路後再試上述核心操作。下載新的工商資料及即時補查仍需網路。

請回報
哪個畫面、做了哪一步、原本期待什麼，以及看到的提示。截圖請只使用假資料；請勿傳客戶檔案、資料庫、備份或金鑰。

目前仍需實機確認
乾淨離線 Windows、螢幕縮放、中文輸入、輔助工具及 Windows 安全提示。候選套件的自動測試通過，也不能取代這些實際操作。
