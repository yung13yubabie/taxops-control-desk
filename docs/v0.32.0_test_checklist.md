# v0.32.0 測試建置檢查清單

這是測試建置，不是發佈版本，沒有 tag 也沒有 GitHub Release。目的是讓實際使用者在真機上
找出自動化測試無法驗證的問題：視覺比例、DPI 縮放、鍵盤操作、以及「這樣操作順不順」。

自動化狀態：118 個測試檔、2,897 項通過、0 失敗。EXE 啟動、SQLite 建立、migration
`0028_annual_compliance` 均已驗證。**視覺與 DPI 完全未驗收**——那是這份清單存在的原因。

## 本次改了四個畫面

其他畫面與 v0.31.0 相同，不需重測。

### 1. 日期欄位（出現在待辦、滯納金試算、租約、固定開立、年度工作、案件）

改動最大的元件。舊版彈窗有 -10年／-5年／-1年／+1年／+5年／+10年 六顆跳轉鍵，加上巨大的
「今天」與「確認」。

請確認：

- [ ] 直接鍵入 `2026-05-21` 可以被接受
- [ ] 游標放在年、月、日任一段時按 Up／Down 只改那一段
- [ ] 月底測試：`2026-01-31` 按 Up 加一個月，應為 `2026-02-28`（不是 03-03）
- [ ] 點日曆圖示開啟彈窗，**點一下日期就套用並關閉**，不需要再按確認
- [ ] 彈窗寬度看起來約 320px，不會蓋住底下 Dialog 的儲存／取消
- [ ] 欄位靠近螢幕底部時，彈窗會往上翻而不是被切掉
- [ ] 「今天」是低調的文字動作，不是大藍色方塊
- [ ] 清除圖示在輸入框**裡面**，不是旁邊另一顆按鈕
- [ ] 已經有日期的欄位，按 Enter 或在日曆上雙擊有反應（舊版這裡是死的）
- [ ] 輸入 `2026-13-45` 這種錯誤格式時，**輸入內容不會被清掉**，錯誤訊息出現在欄位下方

### 2. 滯納金試算

舊版所有輸入擠在上方，下半部一大片空的費率表，最重要的試算結果反而不顯眼。

請確認：

- [ ] 「從案件帶入／手動輸入」是兩個明確的圓鈕，切換時看得出差別
- [ ] 切到手動輸入時，案件與批次選單消失，但已填的期限、繳款日、稅額**保留**
- [ ] 試算結果出現在輸入區下方，是四個數字的卡片（逾期天數／滯納金率／滯納金／應繳總額）
- [ ] 金額靠右對齊、有千分位，`NT$` 不在可編輯的輸入框裡
- [ ] 「計算區間明細」預設收合，沒資料時完全不佔空間
- [ ] 改動任何輸入後，舊的試算結果會消失（不會留著一個對不上的數字）
- [ ] 整頁只有一個垂直捲軸

### 3. 年度工作台

舊版八個 KPI 方塊即使全是 0 也顯示，表格欄位太多把客戶與標題擠掉。

請確認：

- [ ] 沒有風險時，不再出現八個 0 的方塊，而是一句「目前沒有需要處理的年度工作風險。」
- [ ] 有風險時只顯示有數字的那幾個
- [ ] 表格五欄（客戶／標題／工作類型／期限／作業狀態），**1366×768 不需要左右拖**
- [ ] 點選一列後，右側出現工作摘要，不再是下方一整段重複的文字
- [ ] 「開啟明細」在未選取時不存在，選取後才出現
- [ ] 雙擊一列可直接開啟

### 4. 訊息模板

請確認：

- [ ] 「新增模板」是唯一的藍色按鈕
- [ ] 沒選模板時右側是一段說明，不是一大片空白輸入框
- [ ] 選取模板後才出現「編輯模板」「試用模板」，刪除在「更多」裡面
- [ ] 內建模板的編輯與刪除是停用的，滑過去有說明原因的提示
- [ ] 編輯畫面：欄位來源說明預設收合在下方，不再佔據上半部
- [ ] 可用欄位有分類與搜尋，雙擊插入，插入格式明確顯示為「插入格式：【客戶名稱】」

## 全域項目（四個畫面都要看）

- [ ] 每頁只有一顆藍色按鈕，其他是白底或透明
- [ ] 刪除類按鈕是紅字紅框，不是藍底
- [ ] 核取方塊勾選後有明確勾號，不是藍色實心方塊
- [ ] 沒有任何文字上下被切掉
- [ ] 側邊欄收合後仍看得出各模組的圖示，滑過去有名稱

## DPI 縮放（最需要人工的部分）

在 Windows 顯示設定分別切到 100%、125%、150%，每次重開程式後看：

- [ ] 輸入框與按鈕的文字沒有上下裁切
- [ ] Dialog 的儲存／取消永遠看得到，不會被推到螢幕外
- [ ] 日期彈窗不會超出螢幕
- [ ] 表格列高足夠，內嵌輸入框不被切
- [ ] 核心表格在 1366×768 不需要左右拖

125% 與 150% 是重點：日期欄位的寬度下限在這版改成依實際字體推導，就是為了這兩個縮放，
但那是計算結果，沒有人真的看過。

  見 `.ai/DECISIONS.md`

## 請優先回報

1. 任何文字被裁切、按鈕重疊、Dialog 超出螢幕的位置與當時的縮放比例
2. 操作起來卡住或找不到功能的地方（功能被移進「更多」而你覺得不該在那裡）
3. 日期欄位的任何異常——它是六個畫面共用的，錯了影響最大
4. 用詞不對的地方（例如「作業狀態」「工作類型」不是事務所實際說法）
