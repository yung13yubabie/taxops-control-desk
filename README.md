# TaxOps Control Desk

TaxOps Control Desk  。資料預設保存在本機 SQLite，不需登入雲端服務；GCIS 線上補查是可選功能，不影響離線核心流程。

目前版本：`v0.31.0`。本專案已是可執行應用，不是規格骨架。

## 主要功能

- 客戶、案件、索件、任務與工作紀錄管理
- 客戶年度工作台、年度制度預覽、工作明細與收支交易帳
- 固定開立方案、待開立紀錄、批量核對與確認退回
- 客戶特殊要求／備註全文檢視與篩選
- 官方登記資料本機快取、同名多筆選擇與 GCIS 統編補查
- 訊息模板、附件、備份還原與稽核紀錄
- Windows EXE 封裝與啟動 smoke test

## v0.31.0 重點：介面重構第一批

這個版本建立可驗證的設計系統，並以客戶管理頁作為全系統母板。**介面重構尚未完成**，涵蓋範圍僅以下三部分。

**設計系統**

- 全域按鈕不再預設藍底白字。按鈕角色由 Qt dynamic property 決定，共七種：`primary`、`secondary`、`quiet`、`danger`、`dangerQuiet`、`icon`、`link`。未指定角色者一律讀作次要操作。
- 每個導覽頁最多一個 primary。搜尋、清除、重新整理、欄位設定不得是 primary；刪除與永久刪除採紅字紅框，不與主要操作同色。
- 核取方塊恢復平台原生 indicator，勾選狀態有明確勾號，不再是純藍色方塊。
- 工商查詢頁的 primary 是「套用至客戶主檔」而非任一查詢按鈕，因為查詢不改變資料。
- 39 個內嵌 SVG 圖示取代作業系統 standard pixmap；未定義的圖示角色會直接拋出例外，不再靜默回退成資訊圖示。同時修正三個原本錯誤的對應：試算指向資訊圖示、匯出指向純箭頭、新增指向資料夾。
- 字級回到設計文件既有規範：一般文字 14px、表格表頭 13px。先前實際出貨為 13px 與 12px。
- 控件高度扣除 padding 與框線後精確落在 token 上。先前 32px 的設定實際渲染成 46px。
- 側邊欄展開 220px、收合 56px。收合後保留各模組圖示並以 tooltip 顯示名稱；先前收合會隱藏整個導覽列，只留 32px 空條。選取項目改為左側指示條加淡色背景。

**共用頁面結構**

- 新增 `PageHeader` 與 `ActionBar`。頁面標題與操作分離；工作操作靠左、檢視工具靠右，可見操作上限五個，其餘進入「更多」選單。上限在建構時強制，超出即拋出例外。
- 新增 `Inspector` 右側詳情面板，承載選取資料的完整內容與情境操作，取代「選取後在表格下方以純文字重複整列」的做法。
- 空狀態改為標題承載重量、說明輔助，最多一個下一步。

**客戶管理頁**

- 標題列持有唯一 primary「新增客戶」。搜尋框配安靜圖示按鈕，兩個列表篩選收進「篩選」選單。
- 表格預設顯示六欄，1366×768 不需水平捲動。簡稱、聯絡信箱、登記地址、聯絡地址與更新時間改為由「欄位顯示」自行開啟。
- 表格與 Inspector 並排。編輯客戶與租約管理為情境操作；刪除、復原、永久刪除移入「更多」。
- 備註全文與租約明細移至右欄，未選取客戶時完全隱藏，不再固定佔用兩個空框。

## v0.30.0 重點

- 每位客戶每個作業年度只有一個年度工作母體；制度預覽與年度工作台雙向聯動，工作、申報、文件、稅額與服務費狀態分開管理。
- 年度工作明細可編輯、完成、取消、還原與重新開啟；交易帳以正式明細推導應收、已收、代墊與未結餘額。
- 「協作管理」直接連到正式案件、索件、附件與待辦資料；索件選項、附件與待辦均採有上限分頁。
- 客戶主檔分開保存登記／聯絡地址、多筆租約與產業資料；歷史附件保留 owner guard。

## 物件責任與唯一事實來源

年度工作、案件、待辦、流程範本、流程執行與固定開立各有明確責任範圍，記載於 `docs/product_object_model.md`。要點：

- 年度工作是法遵狀態的唯一事實來源。
- 完成年度工作不會連動其連結待辦；完成待辦也不代表案件或年度工作完成。系統中沒有任何隱性同步。
- 固定開立的 pending 代表待確認開立排程，不是應收帳款，介面不得以欠款稱之。

## 開發與驗證

開始工作前依序閱讀：

1. `.ai/spec-kit.md`
2. `.ai/CURRENT_STATE.md`
3. `.ai/TASKS.md`
4. `.ai/DECISIONS.md`
5. UI 工作再讀 `.ai/DESIGN.md` 與 `.ai/UI_REDESIGN_AUDIT.md`
6. 涉及年度工作、案件、待辦或流程時讀 `docs/product_object_model.md`

常用命令：

```powershell
python -m pytest
python -m coverage run -m pytest
python -m coverage report --precision=2
python -m taxops
python -m build_tools.clean_package
python -m build_tools.package_windows
python -m build_tools.smoke_test_exe
```

完整測試約 34 分鐘。長時間執行時不要將 pytest 輸出接給 `tail`，該指令會緩衝至程序結束，輸出檔會一直是空的而看似停滯；請改用 `python -u -m pytest` 並直接讀取輸出檔。

Windows 封裝與人工驗收項目請見 `docs/packaging_checklist.md`。正式發佈檔附在 GitHub Release；repo 內的 `dist/` 是本機建置輸出，不應視為永久下載來源。
