## CRITICAL（1 個）

### C1 — QThread 關窗 crash 風險
- **檔案**：`src/taxops/ui/pages/settings_page.py`
- **問題**：`_run_async()` 啟動背景 worker 後，`SettingsPage` / `MainWindow` 沒有 `closeEvent`。使用者關閉視窗時，若 worker 仍在執行（特別是 `on_download_registry` 做 HTTP 下載），QThread C++ 側可能在 Python thread 尚未結束時被 Qt 析構機制刪除 → undefined behavior / crash。
- **修法**：
  ```python
  # SettingsPage 加入：
  def closeEvent(self, event: QCloseEvent) -> None:
      if self._active_worker and self._active_worker.isRunning():
          self._active_worker.quit()
          self._active_worker.wait(3000)
      super().closeEvent(event)
  ```
  或在 `MainWindow.closeEvent` 中統一處理（需找到 SettingsPage 的 widget 引用）。
